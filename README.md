# 仓库权限分配交互原型

使用「国家 → 海外仓 → 业务线」替代直接选择业务虚拟仓的方式。入口为 `index.html`，无构建步骤或外部依赖。

- 按国家选择海外仓，每个海外仓独立配置业务线，跨国家切换保留已选项。
- 提供国家与海外仓搜索、当前搜索结果全选、仅看已选、业务线全选。
- 支持将当前仓的业务线追加到本国其他已选仓；只追加适用项，保留已有配置，并展示跳过项。
- 底部汇总国家、海外仓及实际「海外仓 + 业务线」组合数；弹窗按国家查看完整权限。
- 已选海外仓未配置业务线时，保存会定位到待配置仓。取消仓库同时移除其业务线，并支持撤销。
- 全部仓库模式包括后续新增的仓库及业务线，切回部分仓库时保留手动配置。
- 保存到当前浏览器本地存储，重新打开可恢复。恢复示例前展示确认。

所有仓库编码与配置均为演示数据。原型不连接真实业务权限系统。

## 本地运行

直接打开 `index.html`，或在本目录运行 `python -m http.server 8768 --bind 127.0.0.1`。

## 上线

公开仓库仅包含 `index.html`、`style.css`、`app.js`、本说明及 `.nojekyll`。
GitHub Pages 使用 `main` 分支根目录发布。授权映射在生产环境应由服务端校验和保存；「全部仓库」需要作为动态权限范围存储。
